## Поддерживаемые версии

Исправления безопасности выходят в последнем релизе.

## Сообщить об уязвимости

Об уязвимостях сообщают приватно по адресу i@voyemu.com, а не в публичной задаче (issue).

Сообщение называет затронутую версию, операционную систему хоста, профиль, шаги воспроизведения и наблюдаемые последствия. Штатные файлы прошивки, диски подготовленных машин, токены доступа и другие секреты к нему не прикладываются.

## Область действия

Voyemu — локальный инструмент. Конечная точка gRPC кадров QNX слушает `127.0.0.1` и требует токен поколения из файла обнаружения. Voyemu API работает как локальный процесс через `voyemu test`. У гостей нет исходящего доступа к сети, если они не запущены с `--network=yes`.

Эта политика не охватывает поведение штатных приложений внутри гостя.
