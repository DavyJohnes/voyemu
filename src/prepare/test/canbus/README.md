# CanBus component regression

CTest `canbus_source` runs [run.cmake](run.cmake) with JDK 25 and the existing `.local/toolchains/java/libraries` and Android build-tool libraries. It runs the eight semantic Java mains against the normal CanBus sources and the existing canbus-hfp fixtures, the cluster theme state test, `CanBusAccStatusTest` against the shared model bridge with the [canbus-model](../fixtures/canbus-model) socket double, `CanBusComponentTest` against the shared component with the [canbus-component](../fixtures/canbus-component) doubles and the same socket double, and the retained real APK manifest dump self-test of `CanbusComponentRegression`. `canbus_oem` also builds the component of 6.0.3, 6.11.1 and 7.3.1 through Artifacts from the imported donor and checks with `CanbusApiParity` that its `BaseCanBusComponent` and `DongfengCanBusComponentImpl` declare the OEM methods listed in [canbus-api](../fixtures/canbus-api) for that firmware and only the Voyemu lifecycle methods besides them. The cluster Binder ABI test disassembles the imported 7.3.1 `QGAPI.jar` and is skipped when `.local/profiles` lacks it. This mode performs no component production.

Compile `src/prepare/java` with `CanbusComponentRegression.java` against the same libraries and run `java -cp CLASSES:LIBRARIES com.voyemu.prepare.CanbusComponentRegression ROOT WORK EXISTING_RUNTIME_QGAPI_JAR VERIFIED_SHA256 [SOURCE_OVERLAY_ROOT]`. The optional overlay is a repository-shaped source root; canonical repository sources are the default. Only the CanBus component is produced through normal Artifacts resolution; the existing selected patched QGAPI artifact is consumed without rebuilding it. Native tools come from `.local/toolchains/native-sdk`, Java tools/dependencies and Android platform from their normal toolchain locations, and immutable donor/signing inputs from the normal profile inputs.

The regression rejects a derived manifest without INTERNET/QGAPI, checks decoded compiled APK manifest, owned classes, Bluetooth ABI ownership, profile runtime library mapping and transitive DEX references from literal reflection roots. It retains receipts in WORK. This does not establish Android classloader execution, dynamic/native linkage or QNX screen acceptance.
