# Voyemu

Voyemu — эмулятор автомобилей Voyah на базе Android (Free, Dreamer, Passion) для macOS, Windows и Linux. Он запускает оригинальную прошивку мультимедиа (Android, два экрана) и приборки (QNX), скачанную с автомобиля пользователя или взятую из файлов OTA-обновления; сама прошивка в Voyemu не входит. Voyemu эмулирует нажатия кнопок руля и ввод параметров автомобиля. Через [Voyemu API](how/api.ru.md) скрипты получают снимки экрана и дерево элементов интерфейса, передают ввод и читают сообщения CAN.

Профиль прошивки описывает оригиналы и их адаптацию; подготовленная машина содержит гостевые образы, ресурсы и записываемые диски.

## Почему Voyemu

### Настоящая прошивка вместо макета

Гости — собственные образы Android и QNX автомобиля, которые пользователь импортирует из своей прошивки. Адаптации — рецепты с `guard` на точные исходные байты, которые они меняют; штатные имена пакетов остаются прежними. Штатные файлы никогда не попадают в репозиторий.

### Профиль — исходник, машина — результат

Профиль в `profiles/` описывает одну прошивку: её оригиналы, рецепты, компоненты и пины. Подготовка превращает его в машину, которая содержит всё нужное для запуска, поэтому подготовленная машина работает без авторского профиля и переносится одним каталогом. См. [профили и машины](why/profiles-machines.ru.md).

### Две операционные системы в одном окне

Приборка и оба экрана мультимедиа видны рядом вместе с кнопками руля и органами управления автомобилем. Гости Android и QNX общаются по межгостевой связи, как в автомобиле. См. [окно SDL3](why/sdl3-window.ru.md).

### Воспроизводимая подготовка

У каждой внешней загрузки есть точная версия, URL и SHA-256, и несовпадение останавливает подготовку до того, как неверный вход попадёт в машину. См. [пины внешних входов](why/pins.ru.md).

### Постоянные данные гостей

Установленные приложения, файлы и настройки лежат на записываемых дисках машины. Они сохраняются после холодного старта и копирования каталога машины, а временное состояние сеанса остаётся в `.local/`. См. [четыре корня `.local`](why/local-roots.ru.md).

### Автоматизация с явными исходами

Voyemu API управляет сеансами: владением, состоянием автомобиля, вводом, наблюдениями UI, снимками экранов и ожиданиями. Каждый отказ сообщает, что операция не началась или что её исход неизвестен, а неизвестный исход запрещает автоматический повтор. См. [Voyemu API](why/api.ru.md) и [коды ошибок](why/error-codes.ru.md).

### Одна реализация для всех хостов

macOS, Windows и Linux используют одну реализацию на C++ с тонкими бэкендами хостов, собранную одним закреплённым набором инструментов Zig. Возможность ведёт себя и описывается одинаково на каждой платформе. См. записи [одна реализация](why/single-implementation.ru.md) и [набор инструментов Zig](why/zig-toolchain.ru.md).
