# Набор инструментов Zig

## Решение

Voyemu собирается закреплённым Zig 0.15.2 на каждом хосте: `aarch64-macos` с SDK из Command Line Tools, `x86_64-windows-gnu` с MinGW-w64 нативно на Windows или кросс-сборкой на Linux и `x86_64-linux-gnu` с базой glibc 2.34. MSVC и Xcode не поддерживаются. Файлы наборов инструментов лежат в `src/dev/toolchains/`.

## Контекст

Voyemu работает на macOS, Windows и Linux. Код хоста — [одна общая реализация на C++20](single-implementation.ru.md). Архивы Zig, CMake и Ninja для каждого хоста закреплены по URL и SHA-256 в `src/app/toolchain.json` в разделе `optionalTools`.

## Альтернативы

**MSVC на Windows и Apple Clang из Xcode на macOS.** Два компилятора с разной диагностикой, флагами и расширениями языка. MSVC устанавливается через установщик Visual Studio, а не одним закреплённым архивом, и не работает на исполнителе CI с Linux.

**Дистрибутив MinGW-w64 GCC или LLVM-MinGW.** Он покрывает только Windows; для macOS и Linux всё равно нужен другой компилятор.

**Системный компилятор каждого хоста.** Его версия зависит от хоста, и сборка перестаёт воспроизводиться по пинам.

## Аргумент

Один архив на хост даёт один компилятор на основе Clang и один набор флагов и предупреждений. Zig поддерживает кросс-компиляцию, поэтому исполнитель CI на Linux собирает исполняемый файл Windows и прогоняет по нему clang-tidy. Архив — обычная загрузка и подчиняется [правилу пинов](pins.ru.md). На macOS файлу набора инструментов нужен только SDK из Command Line Tools, который он находит через `xcrun`.

## Последствия

При настройке всегда передаётся файл набора инструментов Zig; переход с другого набора требует нового каталога сборки. Исполняемые файлы Windows используют ABI MinGW, поэтому библиотеки, которые поставляются только с импортными библиотеками MSVC, не подходят. Zig по умолчанию создаёт отладочную информацию и PDB; файлы наборов инструментов отключают и то и другое для [сборки только Release](release-only.ru.md). Обновление Zig меняет `toolchain.json` и файлы наборов инструментов вместе. Страница [Сборка](../dev/build.ru.md) приводит команды настройки и сборки.
