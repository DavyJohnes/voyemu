# Без Python

## Решение

В репозитории нет файлов и инструментов на Python. Логика сборки — CMake, код хоста — C++, подготовка и проверки разработчика — Java, короткие связующие скрипты — для командной оболочки.

## Контекст

Voyemu собирается на macOS, Windows и Linux закреплёнными наборами инструментов. Python часто выбирают для вспомогательных скриптов сборки, но его версия и пакеты различаются между хостами, а в Windows системного Python нет.

## Альтернативы

**Вспомогательные скрипты на Python.** Каждому хосту понадобился бы закреплённый интерпретатор с пакетами, иначе скрипты зависели бы от того Python, который окажется на хосте.

**Python только для инструментов разработчика.** Второй язык для проверок и генераторов дублирует то, что в репозитории уже делают Java и CMake.

## Аргумент

Java уже нужна для [подготовки](java-preparation.ru.md), а однофайловая программа на Java запускается прямо командой `java File.java`, поэтому проверкам разработчика не нужна дополнительная среда выполнения. Скрипты CMake работают везде, где идёт сборка. Меньше языков — меньше наборов инструментов для закрепления и меньше мест для различий хостов.

## Последствия

Генераторы и проверки пишутся на Java, CMake или C++. Внешние инструменты со своим Python сохраняют его: сборка QEMU из исходников использует `python3` из Command Line Tools на macOS и MSYS2 Python, который Voyemu устанавливает на Windows, а официальный NDK содержит свои инструменты на Python. Python допустим как личный рабочий инструмент вне репозитория.
