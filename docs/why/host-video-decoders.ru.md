# Видеодекодеры хоста

## Решение

Подготовка декодирует штатные стартовые ролики декодером H.264 операционной системы хоста — VideoToolbox на macOS, Media Foundation на Windows и системная libavcodec на Linux. Voyemu не собирает, не скачивает и не распространяет видеокодек. Если на хосте нет декодера или декодер отклоняет ролик, вместо ролика остаётся один чёрный кадр той же длительности.

## Контекст

Штатные стартовые ролики хранятся как H.264 в MP4, и `build` превращает их в кадры формата загрузочной анимации для [окна](../how/window.ru.md#экран-запуска). Декодер H.264 внутри распространяемой программы подпадает под патентную лицензию AVC. Декодирование выполняется один раз при подготовке машины, а недекодированный ролик лишь оставляет чёрной свою часть экрана запуска.

## Альтернативы

**Собрать OpenH264 или FFmpeg из исходников в Voyemu.** Лицензии исходников свободные, но опубликованный релиз содержал бы декодер H.264, которому нужна своя патентная лицензия.

**Скачивать двоичный файл OpenH264 от Cisco в `deps`.** Cisco покрывает патентную лицензию только для файлов, скачанных у Cisco, поэтому каждый хост зависит от сервера вне CI Voyemu. Из некоторых регионов этот сервер отклоняет подключения, и там его пины нельзя ни получить, ни проверить.

## Аргумент

macOS и Windows сами лицензируют и обновляют свои декодеры, а на Linux libavcodec поставляет дистрибутив; Voyemu вызывает их через тонкие бэкенды `os/video_decoder_*` по правилу [одной реализации](single-implementation.ru.md). Чтение MP4, понижение уровня, преобразование цвета и запись архива остаются общими. Без декодера теряются только стартовые ролики, поэтому подготовка записывает это в лог и продолжает работу.

## Последствия

В Windows N без Media Feature Pack нет декодера H.264, и стартовые ролики остаются чёрными. Штатные ролики объявляют уровень 6.0 для кадров 3840×1440, которые укладываются в уровень 5.1 — предел, заявленный для декодера Media Foundation. Поэтому подготовка понижает `level_idc` до наименьшего уровня, в который укладываются размер кадра, скорость макроблоков и опорные кадры потока. Кадры преобразуются по матрице и диапазону, которые объявляет поток. На Linux бэкенд загружает системную libavcodec, если она установлена, а в тестах её заменяет библиотека-заглушка. Экран запуска описан на странице [окна](../how/window.ru.md#экран-запуска).
