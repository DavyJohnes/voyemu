# Разработка

Раздел о сборке Voyemu из исходников, запуске тестов и проверок и изменении закреплённых зависимостей.

- [Сборка](build.ru.md) — CMake с Ninja, только Release, набор инструментов Zig и сборка для Windows с Linux.
- [Тесты](tests.ru.md) — CTest, соседние тесты C++ и тесты Java.
- [Проверки](checks.ru.md) — форматирование, clang-tidy, Checkstyle, Error Prone и проверка документации.
- [CI](ci.ru.md) — рабочие процессы GitHub Actions.
- [Пины](pins.ru.md) — где закреплён каждый внешний вход и как его обновить.
- [Релиз](release.ru.md) — версия, архивы, корень установки и Homebrew.

Выбор средств сборки объясняют [записи о решениях](../why/index.ru.md).
