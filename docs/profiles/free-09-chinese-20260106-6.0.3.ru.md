# free-09-chinese-20260106-6.0.3

Китайская прошивка Free 6.0.3 от 6 января 2026 года на Android 9. Профиль поддерживается с обеими подсистемами: мультимедиа и приборкой.

## Гости

| Параметр | Значение |
| --- | --- |
| Android | 9, API 28, системный образ arm64 |
| Память эмулятора | 4096 МиБ |
| Приборка | QNX с аппаратным адаптером `sa8155-qinggan09` |
| Руль | `free-2021` |
| Ядро разработки | `qinggan-09` |

## Оригиналы

`fetch` импортирует закреплённый архив прошивки `update.zip` по абсолютному локальному пути; `update-mcu.zip` не нужен. Из архива `fetch` извлекает штатные приложения, фреймворк, политики SELinux образов system и vendor, тему по умолчанию, загрузочные анимации и образы QNX `hyp_la.img`, `ifs2_la.img`, `system_la.img` и `ifs2_recovery_la.img`. Подготовка берёт из обеих политик правила `su` машины Android, поэтому `su` ограничен так же, как в автомобиле.

```sh
./voyemu deps free-09-chinese-20260106-6.0.3
./voyemu fetch free-09-chinese-20260106-6.0.3 --source=/absolute/path/update.zip
./voyemu build free-09-chinese-20260106-6.0.3
```

`fetch free-09-chinese-20260106-6.0.3 --source=adb --serial SERIAL` читает те же файлы Android с физического автомобиля через авторизованный ADB закреплённым `adb` из SDK.

Последующие запуски `fetch free-09-chinese-20260106-6.0.3` без `--source` проверяют сохранённые оригиналы.

## Замечания

Приборка хранит `/` и `/var` в образах машины `sysla-gpt-ramdisk-v3.img` и `userdata-qnx6.img` и всегда запускается холодным стартом с этой постоянной разметкой.

Android обнуляет громкость воспроизведения при холодном старте и после восстановления снимка RAM и сохраняет изменения громкости в пределах сеанса. USB Music воспроизводит локальные файлы и реагирует на кнопки руля: пауза, продолжение, следующий и предыдущий трек. DVR записывает с виртуальной камеры, а встроенный в приложение просмотр воспроизводит и удаляет записи.

`initial_state` в `profile.json` задаёт начальные передачу, скорость, температуру снаружи и состояние AEB, см. [модель автомобиля](../how/vehicle.ru.md).

Машина запускает штатные `SystemPolicy` и `QGBus` из импортированной прошивки; они доставляют данные мультимедиа, телефона и навигации по [каналу данных приборки](../how/vehicle.ru.md#канал-данных-приборки).
