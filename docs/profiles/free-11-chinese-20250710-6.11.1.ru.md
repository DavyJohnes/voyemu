# free-11-chinese-20250710-6.11.1

Китайская прошивка Free 6.11.1 от 10 июля 2025 года на Android 11. Профиль поддерживается с обеими подсистемами: мультимедиа и приборкой.

## Гости

| Параметр | Значение |
| --- | --- |
| Android | 11, API 30, системный образ arm64 |
| Память эмулятора | 4096 МиБ |
| Приборка | QNX с аппаратным адаптером `sa8155-qinggan11-611` |
| Руль | `free-2024` |
| Ядро разработки | `qinggan-11` |

## Оригиналы

Оригиналы импортируются из закреплённого архива прошивки `update.zip` по локальному пути; `fetch` извлекает из него нужные образы Android и QNX. Авторизованный ADB с закреплённым `adb` из SDK позволяет импортировать файлы Android, объявленные в `profile.json`, с физического автомобиля, но не получает оригиналы QNX: для них нужен архив прошивки или уже импортированные образы QNX. Файл прошивки `update-mcu.zip` не нужен. Подготовка берёт правила `su` машины Android из политик SELinux разделов system_ext и vendor, поэтому `su` ограничен так же, как в автомобиле.

```sh
./voyemu deps free-11-chinese-20250710-6.11.1
./voyemu fetch free-11-chinese-20250710-6.11.1 --source=path/to/update.zip
./voyemu build free-11-chinese-20250710-6.11.1
```

Файлы Android с автомобиля после получения оригиналов QNX импортирует команда `./voyemu fetch free-11-chinese-20250710-6.11.1 --source=adb --serial SERIAL`. На чистой установке эта команда не заменяет импорт архива прошивки.

## Замечания

Адаптер приборки этого профиля записывает поля [модели автомобиля](../how/vehicle.ru.md) в штатный пакет MCU так же, как адаптер Free 7.3.1; `vehicle.fields` перечисляет гостей каждого поля, а окно показывает органы управления полей, которые не доходят ни до одного гостя, серыми как ограничение профиля.

Экран заднего ряда автомобиля, 1902×540, — третий дисплей Android; его показывает [окно экранов](../how/window.ru.md#экраны). Подготовка импортирует штатное приложение заднего экрана `/vendor/app/ThirdScreen-release-signed/ThirdScreen-release-signed.apk` и запускает его главный экран на заднем дисплее, найденном по уникальному ID, а до готовности Android экран показывает `/system/media/bootanimation2.zip`. Задний экран не задерживает готовность экранов мультимедиа. Профиль оставляет `persist.app.kuwo.support` выключенным, поэтому приложение показывает музыку без Kuwo.

Машина запускает штатные `SystemPolicy` и `QGBus` из импортированной прошивки; они доставляют данные мультимедиа, телефона и навигации по [каналу данных приборки](../how/vehicle.ru.md#канал-данных-приборки).

Плитка Camera открывает обычную камеру, а плитка DVR — штатный вид DVR, обе с виртуальной камерой, см. [камера и DVR](../how/camera.ru.md).
