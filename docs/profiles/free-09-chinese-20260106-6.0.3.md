# free-09-chinese-20260106-6.0.3

The Chinese Free firmware 6.0.3 of 6 January 2026 on Android 9. The profile is supported with both subsystems: the multimedia and the cluster.

## Guests

| Item | Value |
| --- | --- |
| Android | 9, API 28, arm64 system image |
| Emulator memory | 4096 MiB |
| Cluster | QNX with the `sa8155-qinggan09` hardware adapter |
| Steering wheel | `free-2021` |
| Development kernel | `qinggan-09` |

## OEM inputs

Import the pinned firmware archive `update.zip` from a local path; `update-mcu.zip` is not needed. `fetch` extracts from it the OEM applications, the framework, the SELinux policies of the system and vendor images, the default theme, the boot animations and the QNX images `hyp_la.img`, `ifs2_la.img`, `system_la.img` and `ifs2_recovery_la.img`. Preparation takes the `su` rules of the Android machine from both policies, so `su` is restricted as in the vehicle.

```sh
./voyemu deps free-09-chinese-20260106-6.0.3
./voyemu fetch free-09-chinese-20260106-6.0.3 --source=path/to/update.zip
./voyemu build free-09-chinese-20260106-6.0.3
```

`fetch free-09-chinese-20260106-6.0.3 --source=adb --serial SERIAL` reads the same Android files from a physical vehicle over authorized ADB with the pinned SDK `adb`.

Later runs of `fetch free-09-chinese-20260106-6.0.3` without `--source` verify the retained inputs.

## Notes

The cluster stores `/` and `/var` in the machine's `sysla-gpt-ramdisk-v3.img` and `userdata-qnx6.img` and always performs a cold boot with this persistent layout.

Android sets the playback volume to zero on a cold boot and after a checkpoint restore and keeps volume changes within the session. USB Music plays local files and follows the steering-wheel pause, resume, next and previous buttons. The Camera tile records from a virtual camera and has a browser inside the application that plays and deletes the recordings; the DVR tile opens the OEM DVR view, see [camera and DVR](../how/camera.md).

`initial_state` of `profile.json` sets the starting gear, speed, outside temperature and AEB state, see [the vehicle model](../how/vehicle.md).

The machine runs the OEM `SystemPolicy` and `QGBus` imported from the firmware; they deliver media, phone and navigation data over the [cluster data channel](../how/vehicle.md#cluster-data-channel).

The tiles CloudApp, WecarFlow, HiCar, Bill and FreeBaike open the OEM applications of the firmware unchanged; without the cloud services, the phone or the network of the vehicle they show their own login, connection or error screens.

The Gallery and Video tiles open the OEM applications `com.qinggan.app.gallery` and `com.qinggan.app.video`, the latter also from the iQIYI tile of the second screen; preparation adds to both the pinned ARM64 libraries of the Gallery of the Free Android 11 profiles, so they run on ARM64 hosts without 32-bit support.
