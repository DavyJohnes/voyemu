# free-09-chinese-20221230-nxp-rc45

Китайская прошивка Free RC45 от 30 декабря 2022 года для платы мультимедиа на NXP i.MX 8QuadMax, на Android 9. Профиль поддерживается для мультимедиа; приборки в профиле нет.

## Гости

| Параметр | Значение |
| --- | --- |
| Android | 9, API 28, системный образ arm64 |
| Память эмулятора | 4096 МиБ |
| Приборка | Нет |
| Руль | `free-2021` с маршрутами кнопок этого профиля |
| Ядро разработки | `qinggan-09` |

## Оригиналы

`fetch` импортирует закреплённый архив прошивки `update.zip` по локальному пути и извлекает из него нужные файлы Android, среди них политики SELinux образов system и vendor. Подготовка берёт из обеих политик правила `su` машины Android, поэтому `su` ограничен так же, как в автомобиле. Машина подготавливается только с мультимедиа.

```sh
./voyemu deps free-09-chinese-20221230-nxp-rc45
./voyemu fetch free-09-chinese-20221230-nxp-rc45 --source=path/to/update.zip
./voyemu build free-09-chinese-20221230-nxp-rc45 --cluster=off --multimedia=on
```

## Замечания

Приборки в машине нет, поэтому `start` запускает только мультимедиа, см. [запуск и сеансы](../how/launch.ru.md).

Плитки HiCar, Bill и FreeBaike открывают штатные приложения прошивки без изменений; без облачных служб, телефона и сети автомобиля они показывают свои экраны входа, подключения или ошибки.
