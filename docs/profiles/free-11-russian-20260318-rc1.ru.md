# free-11-russian-20260318-rc1

Экспериментальный профиль. Заводская сборка и холодный старт ещё не прошли полную приёмку.

Русская прошивка Free Sport+ 2026-03-18 RC1 на Android 11. Профиль берёт Android-оригиналы из снимка разделов машины, а не из архива обновления. В снимке нет QNX-образов, поэтому профиль собирается без приборки.

## Гости

| Пункт | Значение |
| --- | --- |
| Android | 11, API 30, системный образ arm64 |
| Память эмулятора | 4096 МиБ |
| Приборка | Нет |
| Руль | `free-2024` |
| Ядро разработки | `qinggan-11` |

## Входы OEM

`fetch` импортирует закреплённый снимок разделов `free-11-russian-20260318-rc1.zip` по абсолютному локальному пути. В снимке лежат сырые `system.img` и `vendor.img` машины и `vbmeta.img`; `fetch` извлекает объявленные в `profile.json` Android-оригиналы из закреплённых образов. Подготовка берёт правила `su` Android-машины из политик SELinux разделов system_ext и vendor, поэтому `su` ограничен как в машине.

```sh
./voyemu deps free-11-russian-20260318-rc1
./voyemu fetch free-11-russian-20260318-rc1 --source=/absolute/path/free-11-russian-20260318-rc1.zip
./voyemu build free-11-russian-20260318-rc1
```

## Заметки

Отпечаток прошивки — `qti/msmnile_gvmq/msmnile_gvmq:11/RQ3A.211001.001/47:user`, патч безопасности 2022-10-05. В снимке нет раздела rescue, поэтому тема OEM и навигационное приложение Dueros из китайских профилей в этот профиль не входят.

Приборки в машине нет, поэтому `start` запускает только мультимедиа, см. [запуск и сеансы](../how/launch.ru.md). Приборку можно добавить, когда QNX-образы снимут с машины командой `voyemu fetch free-11-russian-20260318-rc1 --source=adb --serial SERIAL` и внесут их пины в профиль, см. [участие в разработке](../../CONTRIBUTING.ru.md).

Плитка Camera открывает обычную камеру, а плитка DVR — штатный вид DVR, обе с виртуальной камерой, см. [камера и DVR](../how/camera.ru.md).

Плитка Video открывает штатное приложение видео `com.qinggan.app.video`; подготовка добавляет в него те же закреплённые библиотеки ARM64, что и в штатную галерею, поэтому приложение работает на хостах ARM64 без 32-битной поддержки.
