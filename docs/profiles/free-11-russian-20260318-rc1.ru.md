# free-11-russian-20260318-rc1

Экспериментальный профиль. Заводская сборка и холодный запуск ещё не прошли полную приёмку.

Русская прошивка Free RC1 от 18 марта 2026 на Android 11. Профиль берёт Android-оригиналы OEM из снимка разделов машины, а не из архива обновления; входы QNX-приборки остаются от Free 7.3.1 и импортируются из её пиннованного архива прошивки.

## Гости

| Пункт | Значение |
| --- | --- |
| Android | 11, API 30, системный образ arm64 |
| Память эмулятора | 4096 МиБ |
| Приборка | QNX с аппаратным адаптером `sa8155-qinggan11-731` |
| Руль | `free-2024` |
| Ядро разработки | `qinggan-11` |

## Входы OEM

Импортируйте пиннованный снимок разделов `free-11-russian-20260318-rc1.zip` по абсолютному локальному пути. В снимке лежат сырые `system.img` и `vendor.img` машины и `vbmeta.img`; `fetch` извлекает объявленные в `profile.json` Android-оригиналы из пиннованных образов. QNX-оригиналов в снимке нет: импортируйте их один раз из пиннованного архива прошивки Free 7.3.1 `update.zip` китайского профиля `free-11-chinese-20260731-7.3.1`, чьи QNX-разделы совпадают с этой прошивкой. Подготовка берёт правила `su` Android-машины из политик SELinux разделов system_ext и vendor, поэтому `su` ограничен как в машине.

```sh
./voyemu deps free-11-russian-20260318-rc1
./voyemu fetch free-11-russian-20260318-rc1 --source=/абсолютный/путь/free-11-russian-20260318-rc1.zip
./voyemu build free-11-russian-20260318-rc1
```

## Заметки

Отпечаток прошивки — `qti/msmnile_gvmq/msmnile_gvmq:11/RQ3A.211001.001/47:user`, патч безопасности 2022-10-05. В снимке нет раздела rescue, поэтому тема OEM и навигационное приложение Dueros из китайских профилей в этот профиль не входят.
