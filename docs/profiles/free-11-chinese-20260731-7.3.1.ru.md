# free-11-chinese-20260731-7.3.1

Китайская прошивка Free 7.3.1 от 31 июля 2026 года на Android 11. Профиль поддерживается с обеими подсистемами: мультимедиа и приборкой.

## Гости

| Параметр | Значение |
| --- | --- |
| Android | 11, API 30, системный образ arm64 |
| Память эмулятора | 4096 МиБ |
| Приборка | QNX с аппаратным адаптером `sa8155-qinggan11-731` |
| Руль | `free-2024` |
| Ядро разработки | `qinggan-11` |

## Оригиналы

`fetch` импортирует закреплённый внутренний архив прошивки `update.zip` по локальному пути. Внешний архив `731.zip` и `update-mcu.zip` для импорта не нужны. `fetch` извлекает из `update.zip` нужные образы Android и QNX. Подготовка берёт правила `su` машины Android из политик SELinux разделов system_ext и vendor, поэтому `su` ограничен так же, как в автомобиле.

```sh
./voyemu deps free-11-chinese-20260731-7.3.1
./voyemu fetch free-11-chinese-20260731-7.3.1 --source=path/to/update.zip
./voyemu build free-11-chinese-20260731-7.3.1
```

## Замечания

`build free-11-chinese-20260731-7.3.1 --cluster=off --multimedia=on` в существующую остановленную машину обновляет только её систему Android и сохраняет записываемые диски и приборку, см. [подготовку](../how/preparation.ru.md).

Экран заднего ряда автомобиля, 1902×540, — третий дисплей Android; его показывает [окно экранов](../how/window.ru.md#экраны). Подготовка импортирует штатное приложение заднего экрана `/vendor/app/ThirdScreen-release-signed/ThirdScreen-release-signed.apk` и запускает его главный экран на заднем дисплее, найденном по уникальному ID, а до готовности Android экран показывает `/system/media/bootanimation2.zip`. Задний экран не задерживает готовность экранов мультимедиа. Профиль оставляет `persist.app.kuwo.support` выключенным, поэтому приложение показывает музыку без Kuwo.

Машина запускает штатные `SystemPolicy` и `QGBus` из импортированной прошивки; они доставляют данные мультимедиа, телефона и навигации по [каналу данных приборки](../how/vehicle.ru.md#канал-данных-приборки).

Плитка Camera открывает обычную камеру, а плитка DVR — штатное приложение DVR, обе с виртуальной камерой, см. [камера и DVR](../how/camera.ru.md).

Плитка Video открывает штатное приложение видео `com.qinggan.app.video`; подготовка добавляет в него те же закреплённые библиотеки ARM64, что и в штатную галерею, поэтому приложение работает на хостах ARM64 без 32-битной поддержки.

Плитки CloudApp, WecarFlow, HiCar и Bill открывают штатные приложения прошивки без изменений; без облачных служб, телефона и сети автомобиля они показывают свои экраны входа, подключения или ошибки.
